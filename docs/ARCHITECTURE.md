# Architecture

Core:
Workspace → Projects → Tasks → Files → Activity → Notifications

Publishing:
Social Studio → Scheduled Post → Queue → Provider Adapter → Official Social API

Portable infrastructure:
- PostgreSQL
- Redis
- S3-compatible storage
- Docker Compose

Recommended next additions:
- authentication
- memberships and RBAC
- comments
- activity events
- notifications
- file storage service
- social account connections
- provider credentials
- publishing attempts/retries
- calendar
- audit logs
- AI content assistant
